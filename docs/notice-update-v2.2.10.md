# [공지] Jupyter Live Share 익스텐션 업데이트 안내 (v2.2.10)

안녕하세요.

Jupyter Live Share 익스텐션이 **v2.2.10으로 업데이트**되었습니다.
이번 버전은 **가로 스크롤바 이중 표시 문제**를 수정한 작은 UI 개선입니다.

**1~2분이면 끝나니** 수업 전에 꼭 업데이트해 주세요.

> 수업 외에도 **학생들끼리 스터디**할 때 활용할 수 있습니다.
> 주최자가 세션을 열고 참가자들이 접속하면 코드와 화면을 실시간으로 함께 볼 수 있으니, 스터디 모임에서도 적극 활용해 보세요!

---

## v2.2.10 업데이트 내용

- **가로 스크롤바 이중 표시 수정**: 텍스트/코드(.py, .txt, .md 등) 공유 시 **코드 블록 끝에 붙던 가로 스크롤바**와 **화면 하단 고정 스크롤바**가 동시에 보이던 문제를 수정했습니다.
  - 이제 코드 블록 자체의 가로 스크롤바는 숨기고, **화면 하단의 고정 가로 스크롤바 하나만** 사용합니다. (세로 위치와 무관하게 어디서나 조작 가능)
  - 가로 스크롤 기능(마우스 휠/트랙패드 포함)은 **그대로 유지**됩니다.
  - 노트북(.ipynb) 셀의 가로 스크롤바는 **영향 없이 그대로**입니다.
- 그 외 모든 기능(실시간 동기화, Mermaid, 판서, 채팅, 설문 등)은 **그대로 유지**됩니다.

## 업데이트 방법

이전에 설치해 본 적 있으면 **다운로드 → 설치만 하면 됩니다.**

### 1. 새 버전 다운로드
- 아래 링크에서 `.vsix` 파일 다운로드:
  https://github.com/SeolMuah/jupyter-live-share/releases/latest

### 2. VS Code에서 설치
- VS Code → 좌측 Extensions (`Ctrl+Shift+X`) → 상단 **···** → **"Install from VSIX..."** → 다운받은 파일 선택

### 3. VS Code 재시작
- 설치 후 **VS Code를 한 번 재시작**해 주세요

끝입니다!
