# [공지] Jupyter Live Share 익스텐션 업데이트 안내 (v2.2.9)

안녕하세요.

Jupyter Live Share 익스텐션이 **v2.2.9로 업데이트**되었습니다.
이번 버전은 화면상 변화는 없지만 **보안**과 **대규모 세션 안정성(50~100명)**을 크게 강화한 업데이트입니다.

**1~2분이면 끝나니** 수업 전에 꼭 업데이트해 주세요.

> 수업 외에도 **학생들끼리 스터디**할 때 활용할 수 있습니다.
> 주최자가 세션을 열고 참가자들이 접속하면 코드와 화면을 실시간으로 함께 볼 수 있으니, 스터디 모임에서도 적극 활용해 보세요!

---

## 주요 기능

- **실시간 노트북 공유**: .ipynb 파일의 셀, 출력, 구조 변경을 학생 브라우저에 실시간 전송
- **텍스트 파일 공유**: .py, .txt, .md 등 텍스트 파일도 실시간 공유 (구문 하이라이팅, Markdown 렌더링, Mermaid 다이어그램 렌더링)
- **선생님 커서 공유**: 커서 위치 영구 깜빡임, 라인 하이라이트, 선택 영역 실시간 표시
- **판서 (Drawing)**: 펜/형광펜/지우개로 화면에 판서, 학생에게 실시간 전송
- **Teacher Preview**: 학생 화면을 VS Code 내에서 미리보기 (판서 포함)
- **화면 동기화**: 선생님이 **자기 에디터에서 스크롤/클릭**하면 학생 화면이 그대로 따라옴 (노트북=셀 앵커, 텍스트=줄/블록 앵커). 폰트·창 크기가 달라도 같은 위치 표시
- **실시간 채팅**: 사이드바 + VS Code Viewer 전용 채팅 패널 (하단 터미널 영역)
- **설문조사**: Number 모드(숫자 선택지) + Text 모드(직접 레이블 입력), 1인 1표, 실시간 막대 그래프
- **선생님 표시 이름 설정**
- **다크/라이트 모드**: 뷰어 테마 전환
- **VS Code Viewer**: VS Code 내에서 학생 뷰어 열기
- **Cloudflare Tunnel**: 외부 접속용 URL 자동 생성

## v2.2.9 업데이트 내용

이번 버전은 눈에 보이는 기능 변화는 없지만, 내부적으로 **보안과 안정성**을 대폭 강화했습니다. 기존의 모든 기능(스크롤 동기화, Mermaid, 판서, 채팅, 설문 등)은 **그대로 유지**됩니다.

- **대규모 세션 안정성 (50~100명)**:
  - 연결이 느리거나 끊긴 학생 때문에 서버 메모리가 무한정 쌓이지 않도록 **백프레셔(과부하) 감지 후 자동 정리**를 도입했습니다.
  - 30초 **하트비트**로 응답 없는 유령 연결을 자동으로 정리합니다.
  - 커서·스크롤 같은 **순간성 신호**는 과부하 상황에서만 잠시 생략하되, **코드/출력 내용은 절대 누락되지 않도록** 설계했습니다.
  - 실제 부하 테스트(동시 90여 명 + 느린 연결)로 검증했습니다.
- **보안 강화**:
  - 설문·교사 전용 기능이 **교사 본인만** 호출되도록 세션마다 생성되는 **일회용 토큰**으로 보호합니다. (터널을 거치면 모든 접속이 같은 주소로 보이는 문제를 근본적으로 해결)
  - 학생 브라우저 뷰어에 **CSP(콘텐츠 보안 정책)** 와 보안 헤더를 추가하고, 외부 라이브러리에 **무결성 검증(SRI)** 을 적용했습니다.
  - 서버가 사용하는 **오픈소스 라이브러리의 알려진 취약점을 모두 해소**했습니다 (배포본 기준 0건).
- 기존 기능은 **그대로 유지**되며, 실제 브라우저 로드 테스트로 렌더링·동기화가 깨지지 않음을 확인했습니다.

## 업데이트 방법

이전에 설치해 본 적 있으면 **다운로드 → 설치만 하면 됩니다.**

### 1. 새 버전 다운로드
- 아래 링크에서 `.vsix` 파일 다운로드:
  https://github.com/SeolMuah/jupyter-live-share/releases/latest

### 2. VS Code에서 설치
- VS Code → 좌측 Extensions (`Ctrl+Shift+X`) → 상단 **···** → **"Install from VSIX..."** → 다운받은 파일 선택

### 3. VS Code 재시작
- 설치 후 **VS Code를 한 번 재시작**해 주세요

끝입니다!
